## Alcance
La documentación original del proyecto se publica bajo la misma licencia salvo indicación expresa. LICENSE conserva el aviso de la Free Software Foundation relativo al texto de la licencia. No atribuir a Traza la autoría de textos de terceros.

La obligación de facilitar el código fuente correspondiente al distribuir software cubierto debe cumplirse según la GPL. No significa que una modificación de uso privado deba publicarse para todo el mundo.

Utilizar un compilador GPL no impone automáticamente esa licencia a los programas compilados. Si un futuro runtime o generador incorpora código cubierto en la salida, se deberá definir y revisar ese alcance antes de distribuirlo. Este repositorio no añade una excepción de runtime.
